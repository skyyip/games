# 香港傳說・隱藏典藏

2026-11-29：新增獨立20款，全冊200款。原有180款的內容、普通8%完整循環及金蛋抽序保留。

## 取得及解鎖

每收藏10款原有卡／每完成5次每日挑戰，分別累積1券；舊進度計入，隱藏卡及重複數量不增加收藏券。獨立抽序每20次走遍全套，之後可得重複卡。可用券由既有資產與正式每日完成數減已用券數計算，無額外領取文件。不是不可預測的密碼學隨機；市集已購入同款不會改變抽序。

集齊解鎖香江傳奇前綴及專屬免費主題，純外觀、不提供答題加成。重複卡可沿用市集出售，保留最後一張，費用5%向上取整。

## 畫作及介面

原創 image_gen 港式漫畫，細墨線、墨黑、朱紅與香檳金。五幅1122×1402的二乘二圖集，WebP品質90，只轉換格式，不裁切修改原稿；CSS依左上、右上、左下、右下顯示各幅。原始PNG保留於生成資料夾。圖像為文化意境插畫，非現場照片。

未解鎖僅生成CSS剪影和線索，不建立原圖img／完整卡名或延伸閱讀連結；靜態公開網站的資源本身不具保密性。解鎖後以4:5金邊卡面、暖金掃光和指標反光展示；首次取得播放有限揭卡動畫。離屏延續暫停機制，減少動態偏好停用動畫。
