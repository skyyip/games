# 香港百萬富翁

繁體中文香港文化每日問答遊戲，網址為 `/games/hong-kong-millionaire/`；首頁入口排在遊戲列表最後。

## 遊玩

- 香港時間零時更新，每日一局、15 題四選一；291 題分三個難度池，同日使用相同題組。
- 每題限時 25 秒；提示、modal、重新整理及切換分頁不暫停倒數。
- 答錯保留第 5 題 $8,000／第 10 題 $60,000 保險線；割禾青及超時保留已累積獎金。所有獎金是虛擬港幣。
- 模糊、局部、鏡像、完整插畫及文字題，223 幅原創題圖與香港街頭漫畫封面。
- 50:50、預寫朋友提示及模擬觀眾各一次。提示不是即時 AI，觀眾比例不是玩家實際投票。
- 匿名只存本瀏覽器今日進度；開局前登入 Google／Email 可保存歷史、稱號、錯題、圖鑑與收藏，參與每日／月度／生涯榜。
- 每日榜依獎金、總作答時間、剩餘錦囊排序；成績分享不含題目、答案或 Email。另可明確選擇製作帶有題目的「考考朋友」圖片，預覽後才分享。

## 港式節目與感官練習

- 每日挑戰第1–5／6–10／11–15題有不同燈光及原創合成氣氛音。預設靜音，玩家點擊開啟後才播放，可調音量、關閉背景音及選柔和燈光；遵從系統減少動態設定，背景分頁不播放。
- 水吧阿叔、行山好友、看更伯伯及醒目損友均免費，保留同一份題目線索，只改語氣與原創漫畫外貌。選擇於同一局固定；偏好保存在本機。主持人對白沿用既有答案確認視窗，同題固定，不捏造答對率、不暫停倒數。
- 6條低難度題的原有錯誤選項加入括號笑話，不改正解或題目ID。出局徽章按既有結算資料計算，分享預設不附徽章，玩家可自行勾選。正式稱號與每日榜排序保留。
- 16幅已審定的街角漫畫可抽到探照燈模式：25秒內拖曳、點按或用方向鍵移動光圈。光圈按800×500來源圖片比例換算，細字閱讀題保留原有構圖；換頁、提示及重載不增加時間。
- 街坊遊樂場新增免登入的五題聲音與擦霧練習。聲音題使用6段自行合成的四秒情境音效，清楚標示不是實地或官方錄音；可重播或選文字描述，原有25秒期限不重置。
- 新開擦霧練習會避開今日每日題組，避免預先揭露答案。擦霧按唯一來源格子計算揭露面積；答對且揭露不超過20%／35%／50%，分別獲3／2／1顆觀察星星，超過50%歸零。提供點按／鍵盤逐步擦開，最佳成績及未完成練習只存本機；不發獎金、不計每日榜、不消耗每日機會。

新功能測試：`npm run test:showtime`（先建置並提供`HKM_TEST_URL`及`GRID_RUSH_PLAYWRIGHT_MODULE`）。全部沿用目前Firebase資料格式，無須另部署規則或索引。

## 開發與建置

```sh
cd hong-kong-millionaire
npm ci
npm test
npm run rules:check
npm run review:check
npm run firebase:check
```

在儲存庫根目錄建置全站：

```sh
npm ci --prefix tools
BBL_ESBUILD_MODULE="$PWD/tools/node_modules/esbuild/lib/main.js" PLAYGROUND_BASE_PATH=/games/ node tools/build-site.mjs /tmp/games-built
```

把建置結果內容上傳到 `public_html/games/`，包含 `.htaccess`。不能直接上傳包含裸 Firebase imports 的原始碼；不用上傳 `node_modules` 或 CLI 登入資料。

## 驗證與界線

實際 Firestore Emulator 驗證使用與正式程式共用的交易 payload；第一題、完整結算及越權反面案例已通過。詳見 [VERIFICATION.md](VERIFICATION.md)。逐題驗證採操作白名單，避免舊規則超出 Firestore 1,000 expressions 限制。

此架構使用 Spark 可用的 Auth 與 Firestore，不需 Cloud Functions。匿名每日限制依賴本機儲存，多裝置或多帳戶無法可靠辨識同一自然人；客戶端題庫可讀，倒數不保證杜絕查答案。伺服器答題驗證提供 2 秒網絡寬限，畫面仍按每題 25 秒結束。

作答期間限制選取／複製／剪下題目、選項及提示，並限制題圖的右鍵選單及拖放。帳戶輸入欄、賽後回顧與分享正常運作。這是減少直接複製搜尋的瀏覽器限制，不能阻止截圖、OCR、其他裝置查答案或開發者工具；計時、答案、每日次數與分數仍由既有 Firestore 規則驗證。

Google 實際授權、正式規則與索引部署、實機跨裝置測試仍須在上線環境完成。
