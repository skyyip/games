# 完整回歸與 UX 驗證

日期：2026-10-26（Asia/Singapore）。範圍：`beat-bad-luck/`。

## 已重現並修正的問題

| 影響 | 重現情境 | 修正與驗證 |
| --- | --- | --- |
| 高：部分法寶手勢判斷失敗 | 士巴拿畫一個完整、240 點取樣的圓後仍停在第一步；原本只保留前 95 點及最後一點，後半段軌跡遺失。 | 對整條路徑逐步降採樣，保留起點、最新位置及完整走向。480 點單元測試，以及手機直向／橫向、240 點順逆時針實際指標操作驗證。 |
| 中：操作焦點丟失 | 法寶列表停留一分鐘後，自動刷新把焦點移回 `body`；購買後按鈕變成停用，也無法把焦點放回。 | 刷新保留法寶及擺設焦點；已裝備或升滿級時聚焦相應資料列。購買、維修及升級後讓操作位置留在視野內。 |
| 中：遊戲中有不必要的攤位重建 | 打小人期間，每分鐘仍完整重建隱藏的法寶／擺設列表。 | 遊戲及暫停期間只結算收益資料，返回攤位才重建列表；確認整局無隱藏列表重建，前景暫停九小時持續累積收益，返回亦不重複領取。 |
| 中：新煩惱提示與玩法不符 | 盲盒、六合彩選項顯示「影印魔／點走分身」，但實際沒有分身。 | 盲盒改為來回搓弱點，六合彩改為畫圈弱點，套用既有弱點加分，並補齊中英文提示及實際手勢測試。 |
| 中：小劇場手動操作後立即跳句 | 連續切換小劇場後按「下一句」，原本的三秒全域定時器可能緊接着再跳一次；首輪回歸曾重現 `data-act` 為 2 而非 1。 | 手動操作後預留六秒閱讀時間；新增有狀態標示的自動串戲開關。減少動態偏好預設關閉自動串戲，手動操作仍有效。 |
| 低：調位選單重設 | 放置擺設後，位置選單重建並跳回第一格。 | 保留有效的擺設與位置選項，驗證放到第六格後及定時刷新後仍保留選擇。 |

## 操作微調

- 未能購買的法寶／擺設顯示尚欠的香油錢及功德，並以 `aria-describedby` 連到對應說明。
- 暫停視窗加入名稱、對話框語意及焦點循環；Escape 可暫停／繼續。
- 保留五個純顯示手勢提示、紙人上的實際手勢、固定事件提示區、現有法寶消耗與攤位耐用度規則。

依 `frontend-standards-reviewer` 主頁提供的審查原則檢查來源與執行後 DOM；技能包的附錄清單無法讀取，因此未把此檢查稱為正式 W3C 驗證。

## 執行環境與複驗

- Node v24.19.0、Chromium 154.0.8037.57（Linux）。
- 手機與平板以 Chromium 視窗、觸控及 user agent 模擬；這次沒有實體 iPhone／Android 或原生 Safari 裝置可用。音訊分析、權限失敗、恢復和離線行為已在瀏覽器測試覆蓋。
- 開發站：`http://localhost:5173/beat-bad-luck/`。
- 外部 Playwright 供應時設定 `GRID_RUSH_PLAYWRIGHT_MODULE=/path/to/playwright`；各腳本可從儲存庫根目錄以 `node beat-bad-luck/scripts/<name>.mjs` 執行。
- `KIT_PROFILE=0/1/2/3` 分別驗證四組法寶操作；`KIT_MOTION=normal` 開啟動畫，`KIT_CANCEL_ONLY=1` 單獨驗證暫停取消。
- 預覽：`BBL_ESBUILD_MODULE=/path/to/esbuild node beat-bad-luck/scripts/build-preview.mjs /tmp/previews`，再執行 `node beat-bad-luck/scripts/preview-check.mjs /tmp/previews`。
- 快取更新為 v43；保留既有存檔格式、價錢、法寶倍率、擺設收益及三十日耐用度。
