# 打小人效能驗收（cache v106）

只調整 `beat-bad-luck/`。計分、連擊、88 連擊必殺技、道具次數、經濟、保存格式及每局時間沿用原有規則。

## 實測

同一環境的 Chromium headless，390 × 844，關閉聲音；以 CDP Performance 和 MutationObserver 比較修改前 `2400a23` 與本次修改。每個情境約 4 秒，點拍情境則固定執行 40 次。DOM 數字是整個頁面的屬性／節點變更次數；動畫數字是在取樣結束時仍運行中的時間軸。

| 情境 | DOM 變更：前 → 後 | 運行中動畫：前 → 後 | 主執行緒 TaskDuration／秒減幅 |
| --- | ---: | ---: | ---: |
| 首頁（初次動畫） | 0 → 0 | 12 → 11 | 約 29% |
| 奉神等待 | 1,565 → 6 | 5 → 3 | 約 82% |
| 打小人閒置 | 1,242 → 21 | 11 → 4 | 約 62% |
| 連續 40 次點拍 | 3,866 → 1,056 | 35 → 16 | 約 20% |
| 必殺技演出 | 1,827 → 169 | 58 → 12 | 約 42% |
| 暫停 | 1 → 1 | 5 → 0 | 約 100% |

首頁短暫裝飾動畫結束後，另取樣約 4 秒：0 次 DOM 變更、0 個運行中動畫、0 次 layout。

上述為單次瀏覽器量度，CPU 會受執行環境影響；沒有將其換算成真實手機的電量或溫度減幅。

## 更新內容

- 遊戲畫面輪詢由 20 次／秒降至 10 次／秒，等待步驟 4 次／秒。輸入仍即時計分；時間仍以 `performance.now()` 計算。
- 屬性及內容有變才寫入；停止更新本來已隱藏的舊節奏條。快取靜態節點及未改變的法寶、貴人、記錄、小人紙、預覽圖及下拉選項。
- 小人破損以 60 個平滑層次更新；限制重複擊打演出及碎紙粒子，保留每次有效擊打的分數、手勢及觸感回饋。
- 首頁非必要裝飾播放兩輪後停止；減少背景精靈、全畫面模糊／濾鏡、必殺技重複時間軸。保留四邊火焰及各法寶獨有的主要演出。
- 暫停時同步凍結 CSS 和原生動畫，離開步驟時取消擊打動畫；不可見小劇場不再每三秒輪詢。背景頁面停止遊戲維護計時器。
- 靜音不啟動／恢復音訊硬體；音效及雨聲結束後解除音源、Gain、Filter 連接。麥克風音量分析只在玩家啟用時每秒最多讀取 20 次，停止時取消計時器、關閉串流及 context。

## 驗證

- 182 項單元測試通過，包括音訊連接釋放。
- `scripts/performance-check.mjs`：390／1280px，奉神 2 次 DOM 變更／2 秒、打小人閒置 21 次／4 秒、暫停 3 次／4 秒、背景 0 次／4 秒；檢查穩定 DOM、真實 AudioContext 靜音、暫停恢復、蓄力施放及結束恢復。
- `scripts/combat-feedback-check.mjs`：320／390／812／1280px，包括暴擊、原生觸感、88 連擊、四邊火焰、暫停、重複必殺、完整儀式及清理。
- `scripts/shop-refresh-check.mjs`：四種尺寸、購買確認／取消、弱／強折扣券、低餘額、奉神台原生觸控及鍵盤調位、付費物品完整儀式。
- `scripts/incense-check.mjs`：拒絕及延遲麥克風權限、模擬吹氣、取消、暫停、重開及串流清理。
- 原生滑鼠／觸控：點拍、滑動重扣、來回搓、兩個方向轉圈及雙指內夾均即時計分。
- 額外檢查工作影印小人、股票／豬隊友情緒及原有選擇性事件分支；測試事件時只在測試回應中啟用選擇介面，正式版設定沒有更改。

重跑效能回歸（需要 Playwright／Chromium）：

```sh
GRID_RUSH_PLAYWRIGHT_MODULE=/path/to/playwright-module.mjs \
BEAT_BAD_LUCK_URL=http://localhost:5260/beat-bad-luck/ \
npm --prefix beat-bad-luck run check:performance
```

## 後續靜態介面與背景調整（cache v107）

每次開啟遊戲先靜音，保留其他偏好及存檔；本次開啟期間仍可手動開聲。打小人的背景不再展示紫水晶，也不生成殭屍；已購買的紫水晶仍保留在攤位／奉神台庫存。鬼魂以 7.6 秒的單次 transform／opacity 動畫來回飄動，最後約 2.4 秒逐漸淡出；陰司紙下落由 5.6 秒延長至 6.8 秒。數量仍限制為最多三張紙、兩隻鬼。

連擊條上下火焰縮至 11px、左右 8px；收藏區上方 margin 為零，入口文字統一縮小 10%。移除首頁標題、拖鞋、稱號標籤及選中小人紙邊框的動畫。Modal 開啟／關閉改為 180／150ms 的純 opacity 動畫，移除整個視窗的縮放和位移，並只在過場期間保留 opacity 的 will-change。

183 項單元測試通過。320／390／812／1280px、繁中／英文檢查通過：舊的 sound-on 存檔也以靜音開始、靜態介面與邊框、按鈕字體及間距、較細火焰、鬼魂淡出和清理、較慢紙張、不生成殭屍、紫水晶庫存保留、modal 關閉中重新開啟、焦點及完整儀式。效能回歸仍通過（奉神 2 次／2 秒，打小人閒置 18 次／4 秒，暫停 3 次／4 秒，背景 0 次／4 秒）。上方 CPU 比較表保留 v106 的量度，沒有把它當成 v107 的新 CPU／電量量測。
