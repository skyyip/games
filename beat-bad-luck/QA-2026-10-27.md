## Scope and hardware limits

The exact staged published tree excludes the unrelated unfinished Spark of Tai Hang route and its landing card. GitHub Pages cannot set custom origin cache headers; generated metadata, hashed assets, the release checker and the installed network-first worker provide the static-host update mechanism. `_headers` is included for hosts that honor it.

All interactive acceptance uses Chromium mobile/touch emulation and keyboard/pointer input. Physical iPhone/Android sensors, audio output and OS-isolated Home Screen storage have not been hardware-tested. Shared-origin storage sync and the existing export/import fallback remain in place; this update does not add a cloud account service.
