## 保存與衝突

`life-repository.js` 使用 IndexedDB `career-365.lives.v2`：`lives` 保存不含漫畫的狀態、版本、run及格數；`panels` 以帳戶／run／格ID保存每格。一般操作只追加新格並更新小型狀態，同一交易比較預期版本。匯入或新人生建立新run，清除該帳戶上一個run的漫畫；不影響其他帳戶。初次載入會驗證並遷移原有JSON，保留年齡、選擇、漫畫及資格。若升級後仍有舊版本分頁寫回JSON，另外保留一份舊分頁回復檔，存檔選單可匯出，不用它覆蓋已存在的新版人生。

Web Locks 互斥每份人生的修改；沒有 Web Locks 的瀏覽器仍由 IndexedDB 交易比較版本。舊分頁停止修改並提示載入最新進度，可先匯出當前版本。登入切換期間關閉修改入口，延後回來的舊帳戶讀取不能取代新帳戶狀態。保存完成才顯示「已儲存」。失敗不刪掉上一個已存版本，畫面可匯出備份。

localStorage 只保存小型人生摘要、跨分頁通知及每日回顧等設定；完整 JSON／HTML 繪本和私人雲端快照照常從記憶體內的完整人生產生。IndexedDB 不可用時退回原有本機／記憶體保存並顯示持久化狀態；不宣稱缺乏資料庫交易和Web Locks的舊環境具有同等跨分頁保證。

## 規則與長期自由度

- `entry.theory` 記錄理論／AI練習；受規管職業只有工作情境實作增加`practice`。訓練年期、出師技能、實習及考核仍須同時達標。原有已記錄的實績／已取得資格不追溯清零，避免破壞舊人生。
- 創業月結一次收款。訂單為需求與產能較小者，基礎產能12、每位員工增加10；客源最多60，預設每月保留95%，主人解難改善留客。材料成本為營業額32%，店租及每位員工薪酬維持明示原值。行銷接近上限時效果下降。價格、成本與轉換公式均為遊戲假設，並非行業獲利統計。
- 時代選擇留下每主題最多3份作品、3段服務關係、3段夥伴網絡。作品與已修專精的工作加分合計最多6；夥伴最多改善6個百分點的委託機會；固定服務每段每月$80、全主題最多$480，只有合適且具資格的工作／有限顧問範圍才派發。課堂不會反覆領取月度服務收入。
- 後續輪次會引用累積作品、關係及經驗，輪換擴張／資源／交接情境，不把每輪都當第一次接觸。仍保留五階段市場生命週期、免費退出、兩條企劃上限及虛構未來標示。退休後只回顧，不再推進月份。

職業清單每頁30種，預先建立文字索引；全部405份仍可搜尋及分頁選取。局部DOM更新保留未變動節點、焦點、展開狀態和SVG，漫畫按格ID重用節點。圖像快取有上限，每日成長檢查不重複寫入相同資料。

學習中心並列一年制全日制進修、保留本業兼讀、職業技能／實習及12項短期專精。費用、精力、年期與成果分開列明；全日制開始前清楚說明會結束原工作／事業。原有快捷入口保留。專精操作後焦點留在該課程的可用操作。

## 收支與預算

每月累積`life.flow`，分列例行／額外流入及固定必要／其他支出。資產投入與提取屬本金調度，不假裝固定工作收入。其他支出包含突發診療及自選活動；來源不足的舊存檔無法完整回溯升級前當月的每筆交易，之後月份正常累積。

預算最多12期並止於65歲，按當前薪金／扣款、住屋通脹、孩子成年、醫療保障、習慣、旅居、課程、事業及既有服務計算。首期扣除本月已入帳工資，避免重複收入；不假設升職、新副業、未知疾病、事件或投資價格改變。創業以當前需求固定推算，實際仍會變；這是情境預算而非預測。
