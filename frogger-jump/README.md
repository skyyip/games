# 蓄力連連跳 · Frogger Jump

單人無盡河岸跳躍。長按畫面、滑鼠或空白鍵蓄力，放手自動瞄準下一落點。蓄力以1秒由0升到100%再回落，最大距離540；成功落地計一跳。過遠、過近、荊棘、下沉或空中燈籠魚都可能結束本局。

## 世界前50名與精簡介面（2026-11-28）

世界英雄榜按最高連跳、達成時間顯示前50名，每人一席。第11–50名有清楚數字，前10名沿用徽章；登入玩家仍可查看50名以外的個人排名。移除重複口號、入口副標籤、排行榜普通說明與成功筆數；保留操作、技能、存檔範圍、載入／空榜／錯誤提示。手機分數列以「連跳／最佳」與按鈕分清資訊，移除窄螢幕重複路線標籤。

Google／Email帳戶的email保存在Firebase Authentication → Users；Firestore玩家與公開榜不另存email。完整位置、隱私欄位與部署要求見[FIREBASE.md](FIREBASE.md)。**先發布本版完整Rules，再完整上傳網站；原索引不需更新。**

## 遊戲節奏

- 前20跳保持較寬落點及較少危險，第21–100跳逐步增加難度。三個可見落點最多一個危險，荊棘會自動改瞄後方。
- 普通木樁及睡蓮為主，特殊落點機率由8%逐步升到12%。較小路線提供額外挑戰及獎勵。
- 沉木落地後2.5秒、冰塊3.5秒內跳走。燈籠魚先在兩落點中間預警1.2秒，躍起900ms，再潛水1.4秒；跳躍中相撞才會被吃掉。
- 暫停、隱藏分頁及技能說明會凍結所有遊戲時鐘，並取消尚未放開的蓄力。

## 動物、技能與青蛙幣

38位動物按價格排序，可只看已擁有；每局只選一位動物，不再另設通用技能或河中夥伴。同定位有相同能力，較貴外觀沒有較強的隱藏數值。

| 定位 | 能力與限制 | 低價選擇 |
| --- | --- | --- |
| 剪道 | 清走前方兩落點荊棘，目標加闊8 | 小青蛙免費 |
| 固橋 | 加固腳下及前方第一落點，停止移動與下沉，目標加闊8 | 小企鵝120幣 |
| 護盾 | 啟用後保留至真正擋魚，當前目標加闊8，不防其他危險 | 小水獺160幣 |
| 跨跳 | 下一跳瞄準第二落點，仍需掌握蓄力；真正正中心額外+1幣，只計一跳 | 棉花兔140幣 |
| 微調 | 超出落腳範圍時修正最多28，不給正中心獎勵 | 蛋黃鴨180幣 |
| 救援 | 預先啟用一次失足／下沉救援，成功跳躍保留待命；不防魚及荊棘 | 小藍花朵260幣 |

每局技能由1次起步，每50次成功落地補1次，最多存2次。每跳只能啟用一次，護盾及救援待命期間不重複扣次數。同一落點加闊不疊加，半徑最多90。技能不自動跳躍或增加分數。

完整價格及設計理由見 [BALANCE.md](BALANCE.md)。結算為 `1 + 2 × 跳數 + 10 × floor(跳數 / 20) + 額外獎勵`。20跳正常獲51幣、50跳121幣。離開未完局不獲獎勵，每局只結算一次；每跳額外最多3幣，精準落地、路線及技能獎勵都遵守上限。

郵差蛙、蜻蜓與螢火蟲等訪客亦會出現。這些河岸訪客和14款落點保留；獨立河中夥伴的商店、裝備、顯示及被動觸發已移除。

## 畫面與效能

角色圖像預先準備32格飛行、10格落地及8格蓄力，最多64張，切換角色清掉其他角色。角色圖像最高1.5倍DPR，不因遊戲畫布像素預算變化而清空。磐石小矮人及和煦小牧師使用自然的頭頸、肩臂、握工具及衣服比例。

跳躍及落水沿用顯示器動畫更新；蓄力及移動落點約30fps，靜止、暫停與結算會休眠。跳躍中的HUD約每64ms更新，畫布仍逐幀更新。普通落點落地震動用快取圖像位移，特殊反應仍即時繪製。

畫布最高1.75倍DPR、約140萬像素。水面每次尺寸只畫一次，動物頭像跨尺寸共用完整輪廓快取。減少動態模式保留遊戲時鐘及必要資訊。

## 存檔、登入與部署

本機最高三次為 `frogger-jump.records.v1`，試玩錢包為 `frogger-jump.profile.v2`。Google、Email及匿名Firebase帳戶支援唯一名字、雲端動物／夥伴收藏、跨裝置錢包及世界前50名。名字為2–16個中文字、英文字母、數字、_或-；英文不分大小寫。試玩及登入錢包分開。

待同步結果按帳戶排隊，同局重試不重複發錢，切換帳戶不會把舊回應寫給新玩家。已退役通用技能按舊價一次退款，沒有再次購買入口。本次調價不重算歷史交易，已購收藏及餘額保留。

獨立Firebase專案為 `sky-playground-3c5af`。新價格需要先部署最新 [firestore.rules](firestore.rules)，不需新索引或Functions。從網站根目錄：

```sh
firebase deploy --project sky-playground-3c5af --only firestore:rules --config frogger-jump/firebase.json
```

Auth與資料庫設定見 [FIREBASE.md](FIREBASE.md)，測試及驗證範圍見 [VERIFICATION.md](VERIFICATION.md)。

```sh
cd frogger-jump
npm test
```

受限環境可從網站根目錄用 `node --test --test-isolation=none frogger-jump/tests/*.test.js`（Node22+）。瀏覽器測試用 `FROGGER_URL` 指向本機建置網站、`GRID_RUSH_PLAYWRIGHT_MODULE` 指向Playwright；渲染測試另用 `BBL_ESBUILD_MODULE` 指向esbuild。正式網站使用根目錄建置工具後上傳，勿直接上傳含裸Firebase import的原始碼。

## 夥伴能力整合及舊購買遷移

河蟹／河狸／鯊魚／魔鬼魚／河馬的支援由剪道／固橋／護盾／微調／救援動物技能承接；錦鯉精準獎勵加入跨跳動物技能。僅在發動跨跳且未經修正的正中心落地時額外+1幣，與其他獎勵合計仍最多額外3幣，不會在自動跨荊棘時免費觸發。沒有額外的被動支援次數，每局技能仍從1次開始、每50跳+1、最多存2次。

舊本機存檔載入後立即按目前已知售價退回夥伴青蛙幣並刪除退役欄位；雲端以交易同時退幣及刪除欄位，重讀／並行讀取不重複退幣。全部六位夥伴合計1880幣；未曾退還的舊通用技能另按既有規則退款。原有動物、分數及未結算紀錄保留。
