    THE GAME PLAN +
    1. Read the growth stage. Normal: fling up. Bud: double-tap. Flower: hold still for 1s, then fling up. Every throw finds the mouth.
    2. Make a chain. Hold normal/bud Pikmin for 0.5s, or flowers for 1s, until the thin ring fills. Trace others of the same stage, then finish with an upward flick. Release without a flick to cancel.
    3. Watch them grow. Challenge mode changes states every 3–8s: 1–5 buds bloom, 1–5 flowers return to normal, and 1–10 normal Pikmin become buds. Held, linked or flying Pikmin are protected.
    4. Clear all 30. The last arrival stops the clock. Each mode keeps its own fastest three.
