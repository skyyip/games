        About Stone Skip / 玩法介紹

        Stone Skip — Stone Skipping Game

        Free browser game · 1 player · English / 繁體中文

        A solo stone-skipping game with an adjustable release angle. The result is an arcade distance and bounce count.

        打水漂：單人打水漂遊戲。選好出手角度，使用手機動作、滑動或鍵盤蓄力，把石頭拋向河面，挑戰距離及彈跳次數。

        How to play

        1. Set the release angle and choose phone motion or swipe controls.
        2. Start the round; throw with the selected control, or use keyboard charging.
        3. Watch the stone’s flight and skips, then review the distance and bounce count.

        Play in a modern phone or desktop browser with JavaScript enabled. No account or app download is required. Choose 中 / EN on the playground for Traditional Chinese or English.
